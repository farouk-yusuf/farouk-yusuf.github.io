# Local typefaces

DM Sans and Manrope variable WOFF2 Latin fonts, retrieved through Fontsource's jsDelivr distribution on 17 October 2026:

- https://cdn.jsdelivr.net/fontsource/fonts/dm-sans:vf@latest/latin-wght-normal.woff2
- https://cdn.jsdelivr.net/fontsource/fonts/manrope:vf@latest/latin-wght-normal.woff2

The downloaded files are committed so site rendering does not depend on a font CDN. Their SIL Open Font Licence notices are included in this directory. Refresh deliberately and preserve the licences.
