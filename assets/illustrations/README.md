# Sector illustrations

Original SVG illustrations created for this portfolio: local government, housing, water services and healthcare. They are contextual illustrations, not photographs of the named organisations or their premises. No external image service is required.

## Journey illustrations

`journey-walker.svg` is an original, editable SVG character inspired by the supplied walking illustration: green jacket, navy backpack, blue trousers and red walking shoes. The later user-supplied `boy-going-trip-background.zip` (Illustrator, EPS and JPEG artwork) informed the traveller styling and headphones; the editable character uses a low haircut rather than a quiff. It is a build template; `$carry` is replaced with milestone patches by the Python generator. CSS rotates limb groups for continuous, scroll-triggered walking poses and changes outfit layers at graduation, marriage and the final business chapter.

`journey-partner.svg` is a generic illustrated partner in a wedding dress, shown only at the marriage stop. Neither illustration substitutes for the supplied headshot or claims to reproduce a person’s likeness. `journey-toolkit.svg` defines the six thematic milestone symbols, reused in the chapter cards, lower legend and backpack patches. All illustrations are local SVGs; no animation or image service is required at runtime.
