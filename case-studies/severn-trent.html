Requirements and reporting scope

Simulated workplace brief

During an annual wastewater performance review, I was asked to check the monitoring return, explain the reduction in recorded spills and identify sites for maintenance or further investigation. I first separated the reporting decision from the operational decision: explaining the annual figures requires different evidence from approving work at a specific site.

I used my requirements framework to define the measures, comparison periods, data checks and intended users. The analysis produces a performance pack and review lists. Engineering assessment, environmental risk and scheme costs would be needed before investment could be approved.

Requirements summary
Business problem
Recorded spills fell sharply, but rainfall, monitor availability and changes in the reporting population could affect the comparison.
Core questions
Do the annual figures reconcile? How much context does rainfall provide? Which monitors need attention? Which high-spill sites report no improvement action?
Business relevance
Support a clear performance report and give maintenance, operations and asset-planning teams specific records to investigate.
Defined scope
Environment Agency annual returns for 2020–2025, Midlands rainfall and a 2025 Excel performance pack. No spill volumes, event-level rainfall, scheme costs or measured environmental benefits.

Duration conversion and field-mapping logic
def to_hours(v):
    """Duration arrives as float hours (2020-23), timedelta (2024-25) or time-of-day (<24h, 2025)."""
    if v is None or (isinstance(v, str) and v.strip() == ""): return np.nan
    if isinstance(v, dt.timedelta): return v.total_seconds() / 3600
    if isinstance(v, dt.time): return v.hour + v.minute / 60 + v.second / 3600
    if isinstance(v, dt.datetime):  # Excel serial >= 1 day stored as date from 1899-12-30/31
        return (v - dt.datetime(1899, 12, 30)).total_seconds() / 3600
    if isinstance(v, str):
        m = re.match(r"^\s*(\d+):(\d{2}):(\d{2})\s*$", v)
        if m: return int(m[1]) + int(m[2]) / 60 + int(m[3]) / 3600
        try: return float(v)
        except ValueError: return np.nan
    return float(v)

03

Recorded spills fell as rainfall fell

A storm overflow can release sewage when the sewer system is overwhelmed. Event Duration Monitoring records when a discharge occurs and how long it lasts; it does not measure the volume released. The annual count uses a defined 12/24-hour grouping rule, so it is not a simple count of every discharge start.

The drier year is relevant context, but a 28.4% fall in rain does not mean spills should fall by the same percentage. Local storm intensity, network conditions, monitor availability and improvement work can all affect the recorded result. I therefore used a second comparison before interpreting the reduction.

04

Similar annual rainfall provides a second comparison

I compared 2022 and 2025 because their annual Midlands rainfall totals were close. I also restricted each year’s average to monitors operating at least 90% of the year, reducing the influence of missing monitoring time.

Comparison limits

The 90% threshold reduces one source of bias; it does not recover missed events or create a fixed set of assets. Similar annual rainfall can conceal very different storm patterns. The result is consistent with improved performance, but cannot quantify improvement caused by Severn Trent’s work.

Rainfall-model calculations and assumptions

I fitted a straight line to annual rainfall and average spills for 2020–2024, then evaluated 2025 against that line. The fitted slope associates the rainfall change with about 46% of the observed fall in the qualifying-overflow average. Five annual observations, changing cohorts and regional totals are insufficient to attribute a causal share to weather or calculate the effect of investment.

Persistent high-spill screening adds a longer view

To look beyond a single year, I linked assets across 2023–2025 and retained sites with at least 90% monitor operation in every year. A separate, model-adjusted screen identifies 74 persistent high-spill sites; 17 report no improvement action in 2025. This is a supplementary investigation list, distinct from the 76 observed high-spill sites.

The 74 sites recorded 4,895 spills in 2025: 13.4% of all recorded Severn Trent spills, or 18.9% within the narrower 1,802-site panel. The denominator changes the interpretation. Some sites qualify after adjustment despite recording fewer than 60 spills in 2025.

Investment decision

Use this screen to select sites for evidence gathering. Local rainfall, hydraulic constraints, environmental sensitivity, existing work and cost would be needed to compare investment options. The list does not demonstrate an optimal allocation of capital.

Linked-panel construction and model-adjusted thresholds

The script links 2025 assets through 2024 IDs and the supplied old-ID field for 2023. It retains 1,802 sites with spill counts and monitor operation of at least 90% in all three years, then scales each year’s count using the exploratory regional rainfall model. All three adjusted values must reach 60. This is a screening model, not an engineering design assessment.

linked = panel.dropna(subset=["spills_2023", "spills_2024", "spills_2025"])
reliable3 = linked[(linked[["op_2023", "op_2024", "op_2025"]] >= 90).all(axis=1)].copy()
# rainfall adjustment: scale each year's count to a 'typical wet year' (1,000mm) using the fitted model
ref = a + b * 1000.0
for y in (2023, 2024, 2025):
    reliable3[f"adj_{y}"] = reliable3[f"spills_{y}"] * ref / (a + b * mid[y])
reliable3["adj_mean"] = reliable3[[f"adj_{y}" for y in (2023, 2024, 2025)]].mean(axis=1)
reliable3["years_at_or_above_60_adj"] = (reliable3[[f"adj_{y}" for y in (2023, 2024, 2025)]] >= HIGH).sum(axis=1)
reliable3["persistent_high"] = reliable3.years_at_or_above_60_adj == 3
reliable3["no_improvement_2025"] = reliable3.improvement_2025.astype(str).str.startswith("No improvement")
# not improving: 2025 rainfall-adjusted count at least as high as the 2023-24 adjusted average, from a material base
reliable3["adj_2023_24"] = reliable3[["adj_2023", "adj_2024"]].mean(axis=1)
reliable3["not_improving"] = (reliable3.adj_2025 >= reliable3.adj_2023_24) & (reliable3.adj_2023_24 >= 30)

Analytical limits and review notes

Annual spill counts do not measure discharge volume or environmental harm. Regional annual rainfall cannot describe individual storms. Qualifying monitor cohorts change between years; the five-observation rainfall model does not establish causation. Source reconciliation and exception resolution require the original files and service-owner input. The website reads committed outputs rather than rerunning the pipeline without its raw inputs.
